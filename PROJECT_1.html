Requisiti

GOAT ClipBot è progettato principalmente per Windows 11 a 64 bit.

Sistema Windows 11 64-bit
RAM minima consigliata 16 GB
RAM consigliata 32 GB per elaborazioni lunghe
CPU Intel o AMD moderno
GPU NVIDIA opzionale ma consigliata
Software Python 3.11 + FFmpeg

È necessario inoltre disporre di spazio libero sufficiente per VOD, file temporanei e clip generate. Alcune operazioni richiedono una connessione Internet.
